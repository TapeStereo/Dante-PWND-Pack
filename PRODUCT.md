# DVS Repair

Отдельная переносимая утилита Windows для автоматической замены переданных пользователем файлов DVS. Это самостоятельный проект; приложение «Дантес» рядом не меняется.

## Подтверждённый сценарий

В главном окне одна кнопка «Вылечить DVS от жадности». Встроенные файлы: dvs_service.exe и три файла Licensing из C:/Users/user/Desktop/Dante. Только папка Audinate, с автоматическим поиском установки по зарегистрированной службе. Открыть диспетчер задач, остановить Dante Virtual Soundcard Manager, сохранить оригиналы, скопировать файлы, вернуть исходное состояние службы, предложить перезагрузку. Перезагрузка только при явном согласии.

Резервные копии сохраняются рядом с оригиналами: файл сервиса в <папка DVS>/backup/<дата-ID>/, лицензии в <Licensing>/backup/<дата-ID>/. Повторные запуски сохраняют предыдущие копии. Индекс восстановления записывается в обе папки; журнал и результат — в backup сервиса. Версия остаётся 1.0.

## Платформа и ограничения

Windows 10/11 с .NET Framework 4.8 и установленной DVS. Один EXE с ZIP-ресурсом, без соседних payload-файлов и сетевых загрузок. Права администратора запрашиваются при нажатии кнопки. Тесты не меняют установленную DVS. Поставка подготовлена для набора DVS 4.4.1.3; переносимость лицензии и совместимость с иными версиями DVS не проверены.

## Визуальное направление

Запрошен Y2K Holographic. Светлый перламутровый фон, серебристая полоса, циановые и розовые переливы. В версии 1.0 переданный пользователем хромовый логотип DVS PWND! встроен в окно и иконку EXE. Круглый диск, крупное DVS, заголовок «Файлы на свои места.», подписи Y2K / HOLOGRAPHIC и про один EXE удалены по размеченному скриншоту. Нативное окно Windows и доступная клавиатурой единственная кнопка. Понятный статус, последовательный прогресс, никаких вымышленных сведений о здоровье аудио.

## Контракт экрана

Режим Operate, кодовая реализация в WinForms. 900×640 логических пикселей. Точный информационный текст: «Файлы сервиса и лицензии - внутри программы. Исходные файлы будут сохранены в backup.». Пользовательский логотип справа, реальный найденный путь, три стадии в одной полосе, одна широкая кнопка и строка статуса. Пункт 03: «Обязательно перезагрузить ПК после выполнения». Фирменное взаимодействие: подсветка кнопки плавно изменяется за 220 мс при наведении и уходе курсора; анимация уважает системное отключение эффектов Windows. Контур и фон кнопки рисуются с трёхкратным разрешением и сглаживанием; бинарное обрезание Region не используется. Текст и значки остаются в нативном разрешении. Напротив DVS REPAIR стоит «Developed by TapeStereo», только TapeStereo — ссылка https://github.com/TapeStereo. Доступность: нативная семантика кнопки и LinkLabel, Enter/Space, видимая скруглённая фокусная рамка, текстовое сообщение при каждом состоянии, высококонтрастная системная палитра. Перезагрузка обозначена как обязательная для завершения, но запускается только после явного согласия пользователя.
