DVS Repair 1.0 — переносимая утилита Windows.

- Подпись **Developed by TapeStereo**; имя открывает https://github.com/TapeStereo.
- Хромовый логотип в интерфейсе и иконке EXE.
- Одна кнопка для остановки DVS Manager, резервного копирования и замены встроенных файлов.
- Автопоиск установки только в папке Audinate.
- Backup рядом с оригинальными файлами, с отдельной папкой каждого запуска.
- Проверка SHA-256, автоматический откат при обычной ошибке.
- Сглаженный контур кнопки и плавная подсветка наведения.
- Напоминание об обязательной перезагрузке после успешного выполнения.

Для запуска скачайте **DVS-Repair-v1.0.exe**. Требуются Windows 10/11, .NET Framework 4.8 и установленная Dante Virtual Soundcard.

Самопроверка: **14 сценариев пройдены**. Проверки выполнялись во временных папках без изменения установленной DVS и без перезагрузки. Реальная работа DVS и лицензии на другом ПК не проверялась.

В релиз также входят исходники, инструкция, превью, отчёт проверок и SHA-256 файлов.
Файлы сервиса и Licensing встроены в EXE; отдельно в репозитории и архиве исходников они не публикуются.
