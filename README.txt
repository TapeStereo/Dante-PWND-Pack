DANTE PWND PACK 1.1
Developed by TapeStereo — https://github.com/TapeStereo
https://github.com/TapeStereo/Dante-PWND-Pack

Windows 10/11 x64, .NET Framework 4.8. EXE около 556 МБ.
Для установки рекомендуется не менее 4 ГБ свободного места.

Нажмите «СДЕЛАТЬ КРАСИВО» и подтвердите запрос администратора:
1. Установка DVS 4.4.1.3.
2. Установка Dante Controller 4.15.0.10.
3. Backup оригиналов и замена встроенных файлов DVS.

Оба установщика, сервис и файлы Licensing находятся внутри EXE.
Подходящие установленные версии пропускаются; более новый Controller
сохраняется. DVS новее 4.4.1.3 блокирует замену. Для замены без установки
используйте ссылку под основной кнопкой.

После выполнения обязательно перезагрузите ПК. Программа предложит это
сделать; перезагрузка начинается только после ответа «Да».

Backup создаётся отдельно для каждого запуска:
  <папка DVS>\backup\<дата-ID>\
  %ProgramData%\Audinate\Licensing\backup\<дата-ID>\

В backup-index.tsv указаны пути оригиналов. В backup сервиса сохраняются
repair.log и result.txt. При обычной ошибке замены выполняется откат.
Откат не удаляет уже установленные приложения производителей.

Журналы установки:
  %ProgramData%\DantePWNDPack\Setup\<дата-ID>\

При ошибке установки следующие шаги останавливаются. Проверьте журнал
и повторите запуск. Если Windows отложила обновление сервиса, сначала
перезагрузите ПК. Во время выполнения не выключайте компьютер.

Установка на чистом ПК, работа аудио и переносимость лицензии на другое
оборудование не проверены. Windows может запросить установку драйверов.

Сборка из исходников:
  payload\dvs_service.exe
  payload\Licensing\<три файла>
  installers\DVS-4.4.1.3_windows.exe
  installers\DanteController-4.15.0.10_windows.exe

  powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1

Самопроверка без изменения установленной DVS:
  Dante-PWND-Pack-v1.1.exe /self-test C:\путь\к\отчёту.txt
