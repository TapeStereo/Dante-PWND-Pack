DVS REPAIR v1.0
==============

ЗАПУСК

1. Перенесите DVS-Repair-v1.0.exe на нужный компьютер с Windows.
   Для запуска достаточно одного EXE: dvs_service.exe и три файла Licensing
   уже встроены в него. Интернет, Python и соседние папки не требуются.
2. На компьютере должна быть установлена Dante Virtual Soundcard.
3. Запустите EXE и нажмите «Вылечить DVS от жадности».
4. Подтвердите запрос Windows на права администратора.
5. После успешного выполнения обязательно перезагрузите ПК.
   Программа предложит выполнить перезагрузку сейчас; без согласия
   пользователя перезагрузка не начинается.

ИНТЕРФЕЙС 1.0

Переданный логотип DVS PWND! встроен в окно и иконку приложения.
Иконка содержит размеры 16, 24, 32, 48, 64, 128 и 256 px.
Удалены зачёркнутые заголовки и подписи. Информационный текст:
  Файлы сервиса и лицензии - внутри программы.
  Исходные файлы будут сохранены в backup.
Пункт 03: «Обязательно перезагрузить ПК после выполнения».
Подсветка кнопки плавно изменяется за 220 мс при наведении и уходе курсора.
При отключённых в Windows анимациях эффект меняется сразу.
Исправлены чёрные углы кнопки; границы и отступы выровнены.
Обводка рисуется с трёхкратным разрешением и сглаживается без жёсткого
обрезания скруглений. Справа от DVS REPAIR добавлено Developed by TapeStereo.
Клик по TapeStereo открывает https://github.com/TapeStereo в браузере.

ЧТО ВЫПОЛНЯЕТ ПРОГРАММА

- Ищет папку установки автоматически по ImagePath службы dvs.manager
  (Dante Virtual Soundcard Manager), затем проверяет стандартные папки.
- Использует только Audinate. Вариант с опечаткой Audiante не используется.
- Ожидаемый путь: C:\Program Files (x86)\Audinate\Dante Virtual Soundcard\.
  Поддерживается другой диск/корневая папка, если служба зарегистрирована
  в папке ...\Audinate\Dante Virtual Soundcard\.
- Проверяет состав, размер и SHA-256 каждого встроенного файла.
- Открывает диспетчер задач и останавливает службу DVS через Windows SCM.
  Если диспетчер задач запрещён политикой Windows, это записывается в журнал;
  служба останавливается независимо от окна диспетчера задач.
- До первой замены сохраняет резервные копии всех заменяемых файлов.
- Заменяет dvs_service.exe в найденной папке установки.
- Копирует три встроенных файла в %ProgramData%\Audinate\Licensing\.
  Обычно это C:\ProgramData\Audinate\Licensing\. Остальные файлы этой
  папки сохраняются. Существующие одноимённые файлы заменяются.
- Проверяет результат копирования. Если служба была запущена, запускает её.
  Если до операции она была остановлена, оставляет её остановленной.
- Предлагает перезагрузку только после успешного завершения.
  В вопросе о перезагрузке по умолчанию выбран ответ «Нет».

РЕЗЕРВНЫЕ КОПИИ И ОШИБКИ

Резервные копии создаются рядом с оригиналами, в папках backup:
  <папка установки DVS>\backup\ДАТА-ВРЕМЯ-ID\dvs_service.exe
  %ProgramData%\Audinate\Licensing\backup\ДАТА-ВРЕМЯ-ID\<файлы лицензии>

Пример для стандартной установки:
  C:\Program Files (x86)\Audinate\Dante Virtual Soundcard\backup\ДАТА-ВРЕМЯ-ID\
  C:\ProgramData\Audinate\Licensing\backup\ДАТА-ВРЕМЯ-ID\

Каждый запуск получает отдельную папку с датой и ID. Предыдущие резервные
копии не перезаписываются. Исходные имена файлов сохраняются.
В обеих папках есть backup-index.tsv с точными путями, наличием и SHA-256
оригиналов. В папке backup сервиса дополнительно находятся repair.log
(журнал шагов и ошибок) и result.txt (результат, исходное состояние службы
и пути обеих резервных копий). После успеха программа показывает оба пути.

При обычной ошибке копирования программа автоматически восстанавливает
уже заменённые файлы и исходное состояние службы. Копии остаются на диске.
Принудительное завершение процесса или отключение питания могут прервать
откат. В этом случае для ручного восстановления остановите dvs.manager,
верните оригиналы по путям из backup-index.tsv и верните службу в состояние,
указанное в result.txt (если файл успел сохраниться). Строка Existed=False
означает, что до операции такого файла не было.

СОВМЕСТИМОСТЬ И ПРОВЕРКА

Целевая платформа: Windows 10/11 с .NET Framework 4.8; на штатных Windows
он обычно уже присутствует. EXE AnyCPU; встроенный сервис остаётся исходным
бинарным файлом пользователя. Для macOS эта утилита не предназначена.

Файлы взяты из предоставленного набора DVS 4.4.1.3. Совместимость с другими
версиями DVS и работа переданных данных Licensing на другом ПК не проверены.
Приложение переносит файлы; успешная проверка SHA-256 подтверждает копирование,
а не работоспособность аудио или активации на произвольном оборудовании.

Проверены в изолированных временных папках: извлечение встроенных файлов,
копирование, резервные копии, сохранение посторонних файлов, откат после
каждого шага, реальная блокировка файла и обнаружение повреждённых данных.
При сборке установленная DVS, её служба и лицензии не изменялись.
Проверка реального применения и последующей работы DVS ещё не выполнялась.

ИСХОДНИКИ

Исходники находятся в DVS-Repair-v1.0-source.zip. Для пересборки:
  powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1

Достаточно компилятора C# из .NET Framework Windows. При пересборке поместите
в payload файл dvs_service.exe и папку Licensing. Эти входные файлы отдельно
не публикуются и не входят в архив исходников; они встроены в готовый EXE.
Для своего набора файлов:
  powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -PayloadRoot ПУТЬ_К_ФАЙЛАМ

Встроенная самопроверка без изменения установленной DVS:
  DVS-Repair-v1.0.exe /self-test C:\путь\к\отчёту.txt

Снимок интерфейса без выполнения замены:
  DVS-Repair-v1.0.exe /render C:\путь\к\preview.png 1 idle
  (масштаб 1 или 1.5; состояния idle, hover-mid, hover, progress, success, error)
